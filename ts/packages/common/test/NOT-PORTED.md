# Rust tests not ported as written

Every test of `crates/slopmax-common` has a TypeScript test with its name
(17 of 17). None was left out. These run against a changed mechanism and
say so here:

| Rust test                                           | File                | What changed, and what covers the rest                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------------------------------- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `round_trips_through_text_and_serde`                | `test/time.test.ts` | Timestamps are epoch milliseconds (DECISIONS.md, "Time"), so the round trip adds 123 ms where the Rust adds 123 456 789 ns. serde is `TimestampFromString` (a `Schema`) plus `JSON.stringify`/`JSON.parse`. Reading nine fractional digits is still checked: the jiff line `.855123456Z` reads back as `…855` ms, and "parsing trims, reads leap seconds as 59, and ignores digits past nine" covers longer fractions. |
| `the_default_level_writes_warnings_and_errors_only` | `test/log.test.ts`  | The Rust flips the private `COLOR` atomic and calls the `warn!`/`info!` macros; the port has no macros, so the test calls `log.configure({ color })` and the `log.warn`/`log.info` functions. "lines read {time} {LABEL} {message}, colored only when asked" checks the exact bytes, colored and plain.                                                                                                                |
| `labels_line_up_and_colors_tell_levels_apart`       | `test/log.test.ts`  | `Vec::dedup` counts distinct adjacent colors; a `Set` counts distinct colors, which is the stronger check.                                                                                                                                                                                                                                                                                                             |
| `civil_conversion_matches_known_days`               | `test/time.test.ts` | `days_from_civil` and `civil_from_days` are private in Rust; the port exports them from `time.ts` so the test can reach them.                                                                                                                                                                                                                                                                                          |
